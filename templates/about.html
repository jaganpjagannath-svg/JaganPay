Architectural Specification

About JaganPay

An advanced AI-powered UPI payment simulation platform engineered to showcase production-grade fintech patterns, event-driven automation, and security architectures.

Backend & Persistence

Engineered with Python 3.13 and Flask using factory patterns, SQLAlchemy ORM, database connection pooling, and optimistic locking to prevent race conditions during simulated balance deductions. Compatible with both cloud PostgreSQL and local SQLite fallback.

Security & Mandatory OTP

Employs salted SHA-256 for one-time passwords, bcrypt for demo PINs and passwords, session fixation countermeasures, CSRF mitigation, Content Security Policy headers, and fine-grained Role-Based Access Control (RBAC).

AI Copilot Architecture

Direct integration with the official Google GenAI Python SDK (Gemini 2.5 Flash). Enriched with user transaction context, the assistant categorizes expenses and suggests budgeting heuristics without ever issuing regulated financial advice or executing funds.

n8n Automation Dispatcher

Connects 8 modular n8n workflows through asynchronous daemon workers. Features short timeouts, retry suppression, and isolated failure domains to guarantee that Core Banking operations remain 100% available even if webhook nodes are unreachable.

Mandatory Demo Disclaimer

JaganPay is strictly a simulation environment. It does not interface with the National Payments Corporation of India (NPCI), real-world banking APIs, card networks, or monetary reserve systems. All currencies shown (₹) and account balances are demo variables created for software demonstration purposes.
