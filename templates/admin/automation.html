How to Import Workflows into n8n

1. Ensure n8n is running locally or in your cloud environment (e.g. n8n start at http://localhost:5678).

2. In the n8n UI, navigate to Workflows → Import from File.

3. Select any of the 8 modular workflow blueprints saved in the project's /n8n directory:

registration.json
otp.json
payment-success.json
payment-failure.json
risk-alert.json
daily-summary.json
support.json
admin-report.json

4. Activate the workflows. If n8n is unavailable, JaganPay automatically suppresses connection errors and maintains 100% platform uptime.
