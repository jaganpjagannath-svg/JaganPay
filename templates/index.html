Frequently Asked Questions

Understanding the Simulation

Is real money or a real bank account involved?

No. JaganPay is 100% an offline payment simulation platform created for portfolio presentation and educational demonstration. It never connects to real bank APIs, NPCI UPI rails, or credit card processors.

How does the mandatory OTP work in development?

OTP codes are cryptographically salted and hashed using SHA-256 before storage. During development, a clearly marked demo indicator displays the generated test code on the verification screen for friction-free testing without requiring a live SMS gateway.

What powers the JaganPay AI Financial Assistant?

The assistant is integrated with the official Google GenAI Python SDK (Gemini 2.5 Flash). If an API key is not configured, it gracefully falls back to an intelligent local heuristics engine so your demo will never crash during a presentation.

What happens if my n8n server is offline?

The webhook dispatcher executes asynchronously with short timeouts and fault-tolerant error suppression. Transactions, registrations, and logins will always succeed normally even if n8n is completely offline.
